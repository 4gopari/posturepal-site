# PosturePal — website

The instructions, screenshots, privacy policy and terms for PosturePal, a macOS
posture reminder that calibrates itself to whoever is using it.

Published with GitHub Pages at <https://4gopari.github.io/posturepal-site/>.

- `index.html` — the whole site, one page, no build step and no dependencies.
- `img/` — screenshots of the app's floating indicator and its menu, captured
  from the running app rather than mocked up.

To change the site, edit `index.html` and push. GitHub Pages redeploys within a
minute or so.
